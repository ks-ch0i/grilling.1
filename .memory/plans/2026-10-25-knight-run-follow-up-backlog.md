# Plan: 마창기사 UX·PvP 기록 및 안정성 개선

## Goal
배포를 제외하고 현재 마창기사 게임의 조작 UX, PvP 결과 조회, 테스트 자동화, 전투 화면 시각 요소를 보완한다. 완료 시 루트 게임 테스트가 CI에서 실행되고, 마을 보관함을 터치로 스크롤할 수 있으며, 키보드 사용자는 마을의 주요 컨트롤을 조작할 수 있다. PvP 사용자는 마을에서 최근 경기 요약을 10개씩 조회할 수 있다. 생성된 기사 애니메이션 시범은 결정적 전투 규칙을 바꾸지 않는다.

저장 무결성과 PvP 상세 데이터 보관은 정책·위협 경계가 확정되지 않았으므로, 이 계획에서는 안전한 후속 구현을 위한 구체적 조사·결정 산출물까지만 만든다. 실제 데이터 삭제와 서버 권위형 저장 전환은 그 결과를 검토하고 별도 확정한 뒤 계획한다.

## Confirmed Decisions
- 작업 후보는 빠른 작업부터 배치하고, 중간·큰 작업도 예상 크기와 의존성과 함께 포함한다.
- 가로 화면의 키보드·마우스·터치를 지원한다. 세로 화면과 오디오는 범위에서 제외한다.
- 생성 이미지 시범은 전투 화면의 기사 한 명이다. 대기, 이동, 접촉 공격, 피격·밀림, 쓰러짐 동작을 제공하고 적은 현재 도형으로 유지한다.
- PvP 이력은 마을에서 열며, 최신 10경기씩 페이지 이동한다. 입력 로그 재생과 장기 통계는 포함하지 않는다.
- 온라인 PvP는 기존 비동기·비시즌 규칙을 유지한다. Azure 리소스 생성·배포와 실환경 검증은 제외한다.

## Ordering and Dependencies
- P01-T01은 루트 게임 회귀 테스트를 반복 실행할 수 있게 한다. 이후 UI와 로딩 변경은 해당 테스트 및 빌드로 검증한다.
- P02-T05 API가 경기별 요약 DTO와 페이지 메타데이터를 제공한 뒤 P02-T06이 이를 화면에 표시한다.
- P02-T07과 P04-T09는 현재 Azure 배포 여부에 의존하지 않는 읽기 전용 분석·결정 Task다. Task 완료 전까지 데이터 삭제나 저장 권한 경계 변경은 하지 않는다.
- P03-T08은 이미지 에셋이 필요하다. 구현 시 AI 이미지 생성 도구로 투명 배경 스프라이트 시트를 만들고, 각 프레임과 애니메이션을 화면에서 검토한다.

## Out of Scope
- Azure what-if, 리소스 생성, 배포, 실제 배포 환경 테스트.
- 세로 화면 레이아웃, 오디오, 적·보스 스프라이트, PvP 장면의 캐릭터 이미지.
- 시즌제, 실시간 PvP, PvP 전투 리플레이, 랭킹 통계 화면.
- 이 계획에서의 PvP 상세 데이터 삭제, 서버 권위형 저장 코드 전환. 해당 작업은 P02-T07/P04-T09 결과와 사용자 승인 뒤 별도 계획으로 확정한다.
