# Plan: 완성된 장비 조합 캐릭터

## Goal
투구·갑옷·장갑·장화·창·말의 조합이 자연스러운 하나의 기마 기사로 보이도록 제작한다. 별도 캐릭터 베이스는 표시하지 않는다. 먼저 Common 기마 1컷을 분리·재합성해 사용자가 확인한 다음 나머지 10컷, 5희귀도, 마을·일반/랭킹 전투·PvP에 확장한다.

## 결정과 경계
- [확정 결정](../decisions/2026-10-28-coherent-equipment-character.md)과 [기존 장비 전용 결정](../decisions/2026-10-27-equipment-only-character.md)을 따른다.
- T01의 재합성 샘플을 사용자에게 보여주고 명시적으로 확인받기 전에는 T02를 시작하지 않는다. T01 결과가 거부되면 같은 Task에서 수정하고 다시 보여준다. 시간이 경과한 것은 확인이 아니다.
- 이 계획 작성 단계에서 코드를 변경하거나 에셋을 생성하지 않는다. 배포와 장비 복구 메커니즘은 범위 밖이다.
