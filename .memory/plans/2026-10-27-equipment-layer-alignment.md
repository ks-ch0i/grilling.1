# Plan: 장비 레이어 전체 정렬

## 최신 결정: 공통 장비 기준으로 캐릭터 재설계

사용자 지시: 기본 갑옷의 자세와 비율을 기준으로 캐릭터 베이스를 다시 만들고, 동일한 좌표의 투구·갑옷·장갑·장화·창·말 장비 레이어를 교체한다. 각 동작과 마을 포즈마다 캐릭터와 장비가 같은 기준을 공유해야 한다. 희귀도는 해당 부위 레이어만 교체한다. 임의의 단일 런타임 슬롯 변환을 폐기하고, 각 프레임에서 확인한 위치를 aligned atlas에 합성한다.

## Goal
무장 장비가 이미 그려진 기수 베이스와 여섯 장비 overlay의 중복·크기 불일치를 제거한다. 일반·랭킹 전투, PvP, 마을 미리보기에서 각 장비가 기수의 해당 부위에 붙어 보이고, 기존 그림체·희귀도 색·12칸 atlas 계약은 유지한다.

## Confirmed Decisions
- 걷기·전투 기수 베이스에서 투구·갑옷·장갑·장화·창을 빼고 기본 천 옷차림의 기수로 교체한다. 포즈 순서는 유지하고 action 프레임은 atlas 픽셀 단계에서 공통 접지선에 정렬한다.
- 기존 30개 슬롯·희귀도 장비 atlas와 색·장식은 보존한다. 기존 별도 마을 입상 베이스도 사용한다.
- 여섯 슬롯별 공통 크기/위치 배치를 4개 걷기 프레임과 6개 전투 프레임에 적용한다. 프레임 인덱스별 런타임 오프셋을 만들지 않는다.
- 마을 기사와 말은 각자 기준 좌표에 맞춘 슬롯별 배치를 사용한다.
- 전투/저장/PvP 시뮬레이션 데이터는 변경하지 않는다.

## Regression Traps
- `knight-actions.png`의 프레임 순서는 기존 전투 animation mapper와 일치해야 한다. 말의 action pose 또는 `ground=244` 기준을 움직이면 게임 충돌은 그대로인데 화면만 뜨거나 가라앉는다.
- `WholeBodyWalk`의 기수 이미지는 `/assets/walk/knight-rider.png`에서 별도로 읽는다. 이 베이스와 프레임 기반 행동 시트 양쪽을 바꾸지 않으면 걷기와 공격 사이에 중복 무장이 다시 나타난다.
- 슬롯 순서는 말→갑옷→장화→장갑→투구→창이다. 창이 캐릭터 뒤로 들어가거나 말을 사람 장비 위에 그리면 겹침이 부자연스럽다.
- 마을은 256px 기준 입상 베이스를 64px로 축소한다. 슬롯 위치는 동일한 atlas 좌표 단위를 기준으로 하고 렌더 scale을 통해 장면 크기에 비례시킨다.
- 뒤집기는 부모/overlay 좌우 반전 계약을 유지해야 한다. 방향에 따라 개별 슬롯에 또 반전을 넣으면 PvP에서 장비가 서로 반대편으로 보일 수 있다.

## Out of Scope
- 장비 외형 ID, 희귀도 표, 아이템 수치, 장착 저장, 전투 판정 또는 PvP ticket 변경.
- 마을 UI 배치·패널 크기 변경, 배경 아트 변경, 새 애니메이션 포즈 추가.

## 2026-10-27 화면 확인 후 수정

사용자가 전투와 마을에서 장비가 신체에서 분리된 화면을 제시했다. 기존 시트에는 잘린 조각이 있어 슬롯별 고정 좌표만으로는 프레임 정렬이 불가능하다. 원본과 희귀도 색을 보존하면서 온전한 장비 조각을 각 동작에 맞춰 별도 atlas로 재구성하고 합성 그룹 전체를 반전한다. 실제 화면 검증은 별도로 필요하다.

## 최신 구현 결정

완성된 기사와 말은 여섯 개 장비 레이어를 조합해 표현한다. 걷기·전투·마을 포즈마다 정렬된 frame을 사용하고 희귀도 변경은 해당 부위 atlas 교체로 처리한다. 좌우 방향은 합성 컨테이너 전체를 반전한다.
