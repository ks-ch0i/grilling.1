# Plan: 기사 장비·배경 아트와 전투 거리 조정

## Goal
장착 장비가 마을과 일반·랭킹·PvP 전투 캐릭터에 보이게 하고, 마을·PvP·5개 챕터 테마의 배경 아트를 적용한다. 일반·랭킹 전투 월드를 4,800px로 줄이고 4~10마리의 일반 적을 세 군집에 겹쳐 배치해 보스까지의 이동 시간을 단축한다. 일반 전투와 서버 검증은 같은 새 배치를 쓰며, 새 v4 적용 시 기존 v3 랭킹 티켓은 즉시 만료한다.

## Status
- complete

## Confirmed Decisions
- 장비 한 종류 파일에 걷기 4컷, 전투동작 6컷, 입상 자세 장비 레이어 1컷을 넣는다. 마을 기본 입상 기사 이미지는 별도 파일로 두고, atlas의 남는 칸은 투명 처리한다.
- 장비 외형은 부위와 희귀도만으로 결정한다. 6부위 × 5희귀도 조합을 공유하고, 장비 기본색에 기존 희귀도 색의 작은 장식과 은은한 빛을 더한다.
- 장비 레이어는 전투 동작과 좌우 방향을 따라간다. 마을 상단에는 말 왼쪽·전신 입상 기사 오른쪽의 약 144×80px 미리보기를 두고, 기존 장비 상세 패널을 유지한다.
- 배경은 부드러운 페인터리 스타일이다. 마을은 변경 마을 광장, PvP는 석조 결투장, 전투 테마는 숲길 → 폐허 마을 → 바위 협곡 → 설산 요새 → 화산 성채 순서로 5챕터 주기 순환한다.
- 전투는 원경 파노라마와 반복 중경·전경의 약한 시차를 쓰고, 마을·PvP는 정지 배경을 쓴다. 바닥 띠와 바닥선 및 `FLOOR_Y=560` 충돌 기준은 유지한다.
- 일반 적 4~10마리는 x=700~3,100의 세 고정 군집에 최대한 고르게 나누고 군집 안에서 같은 x로 중첩 소환한다. 뒤쪽 군집에서 500px 뒤에 보스를 소환한다. 월드 폭은 4,800px다.

## Planning Assumptions
- 군집 앵커는 결정 문서의 선택 범위를 균등 분할한 x=700, 1,900, 3,100으로 사용하고, 개수가 나누어떨어지지 않으면 앞 군집부터 한 마리씩 더 배정한다. 따라서 보스 x는 3,600이다.
- 사용자가 확정: 새 시뮬레이터 버전 v4를 적용할 때 기존 v3 랭킹 티켓은 즉시 만료하고, 새 v4 티켓부터 랭킹 전투에 적용한다. v3 티켓의 30분 TTL 대기나 재생 호환은 두지 않는다.

## Ordering and Dependencies
- P01-T01은 공통 전투 배치 계약과 랭킹 시뮬레이터 버전 전환을 먼저 확정한다. 일반 전투의 직접 생성과 새 v4 랭킹 시뮬레이션이 같은 최신 앵커를 사용하고, 기존 v3 티켓은 전환 즉시 거부되어야 한다.
- P02-T01은 투명 장비 시트와 입상 기사 베이스 아트를 준비한다. P02-T02와 P02-T03은 이 파일명·프레임 계약을 사용한다.
- P02-T02는 공유 장비 레이어 렌더러를 만들고 BattleScene 및 TownScene에 연결한다. P02-T03은 같은 계약으로 PvP 양쪽 snapshot에 연결한다.
- P03-T01은 배경 파일을 만든다. P03-T02는 그 manifest와 파일명을 BootScene·BattleScene·TownScene·PvpScene에 연결한다.
- 각 Task의 검증 명령은 청사진에 적는다. 이 계획 단계에서는 테스트, 빌드, 게임 코드, 자산을 실행·생성하지 않는다.

## Out of Scope
- 일반 적 수 범위(4~10), 적 체력·공격력·이동 속도, 골드·XP·드롭, PvP 전투 규칙, 랭킹 보상 계산 변경.
- 저장 데이터·DB schema·API 데이터베이스 변경, 운영 마이그레이션, Azure 배포, 배포 환경 확인.
- 마을 장비 상세 패널 재설계, 키보드/모바일 조작 개선, 카메라 추적/전투 조작 변경.
- 사용자가 선택하지 않은 배경 테마 추가나 장비 레벨·능력치에 따른 고유 외형 생성.

## Regression Traps
- 랭킹은 `packages/game-rules`의 시뮬레이션으로 서버에서 재생한다. BattleScene만 적 위치나 월드 폭을 바꾸면 같은 입력 기록의 결과가 달라진다.
- 시뮬레이터를 v4로 올리는 시점부터 v3 티켓을 즉시 만료해야 한다. API의 버전 불일치 경로를 우회해 v3 replay를 허용하거나, v3 티켓을 새 v4 규칙으로 재생하면 안 된다.
- 기사의 이동은 4프레임 말 시트와 고정 기수 이미지를 쓰고, 접촉·피격·쓰러짐은 별도 6프레임 기마 시트를 쓴다. 장비 오버레이가 현재 보이는 시트와 frame index를 혼동하면 공격 중 장비가 사라지거나 다른 부위에 어긋난다.
- 기존 `TownScene.refresh()`는 모든 자식을 제거하고 다시 그린다. 프리뷰를 상태 변경 뒤 갱신하지 않거나, 제거된 Phaser 객체를 재사용하면 오래된 장비 모습이 남는다.
- 배경을 씬의 첫 색상 사각형 위에 놓으면 UI나 캐릭터보다 앞에 나타날 수 있다. 배경·바닥·캐릭터·HUD의 depth를 분리하고 기존 상호작용 패널을 가리지 않아야 한다.
- 4,800px 폭에서도 바닥 충돌은 x축 길이와 독립적으로 `FLOOR_Y=560`에 고정돼야 한다.

## Neighboring Findings
- PvP 장면은 현재 경기장과 양쪽 캐릭터를 색상 사각형으로 그린다. 이번 계획의 PvP 장비 렌더링/경기장 배경 작업 안에서 교체한다.
- 생성된 숲길 비교 시안은 `.codex/generated_images`의 미리보기이며 production asset이 아니다. 배경 아트 Task에서 선택한 페인터리 스타일로 실제 에셋을 새로 만든다.
