# Plan: 캐릭터·장비 밸런스와 강화 실패·파괴

## Goal
확정된 2026-10-22 결정에 따라 캐릭터 자유 능력치와 초기화, 장비 강화 성공·실패·파괴, 적 수와 골드 보상을 구현한다. 기존 저장은 v2로 결정적으로 이행하고, 이후 랭킹·PvP 입력은 새 시뮬레이터/밸런스 버전으로 검증한다. Azure 리소스 생성·배포는 포함하지 않는다.

## Confirmed Source
- 결정: [2026-10-22-character-gear-balance](../decisions/2026-10-22-character-gear-balance.md)
- 충돌하는 이전 캐릭터·장비 밸런스 값은 이 결정으로 대체한다. 생명력 흡수 처리와 대성공 안내 문구는 유지한다.
- 기존 온라인 동작과 Azure 배포 보류는 [2026-10-21-internal-online-ranking-pvp](./2026-10-21-internal-online-ranking-pvp.md)의 결정을 따른다.

## Key Contracts
- 저장 상태는 schemaVersion 2다. 최상위 gold는 0 이상의 안전한 정수이며 player에는 availableStatPoints, spentStatPoints, statResetCount를 추가한다.
- 기존 v1 캐릭터는 level, XP, pending level-up, 장비 ID/slot/rarity/level, 재료와 진행도를 보존한다. 새 기본 능력치로 재설정하고 획득 레벨마다 2점을 지급한다. 이전 HP 비율을 보존한다. 기존 골드는 0이다.
- 한 레벨업에서 능력치 포인트를 0~2점 배정할 수 있고 같은 능력치에 중복 배정할 수 있다. 남은 점수는 보유한다. 공격 +5, 방어 +10, 최대 HP +30이다.
- 마을 능력치 초기화는 다음 도전 시작 전만 허용한다. 배정 점수를 반환하고 레벨/XP/장비는 보존한다. 비용은 초기화 횟수 n에 대해 ceil(1000 × 1.5^n)이며 상한이 없다.
- 강화 확률은 시도 직전 강화 레벨의 확정 표를 사용한다. 실패와 파괴를 독립적으로 매 시도 판정하고, 비파괴 실패와 파괴도 재료를 소비한다. 성공한 뒤에만 대성공 5%를 추가 판정한다.
- 강화 증가량·희귀도 배율·특수 효과는 결정 문서의 D03/D04 표와 상한을 따른다. 강화 최대 레벨은 30이다.
- 스테이지 일반 적 수는 4~10 균등 분포다. 랭킹 런은 티켓 seed로 같은 수와 같은 재생 상태를 만든다. 보스는 매 5번째 스테이지다.
- 기준 골드 보상은 일반 적 11, 보스 55, 스테이지 클리어 175다. 이미 처치해 획득한 골드는 사망 재시도에서 보존하고, 클리어 보상은 스테이지 완료 시에만 지급한다.
- 신규 규칙은 simulatorVersion 2 / balanceVersion 2로 기록한다. 과거 스테이지/PvP 결과는 수정·재검증하지 않는다. 오래된 진행 중 티켓은 새 실행기에서 제출할 수 없다.
- PvP의 기존 Elo 레이팅 풀과 점수식은 유지한다. 새/기존 스냅샷 버전은 분리해 서로 다른 규칙의 플레이어를 매칭하지 않는다.
