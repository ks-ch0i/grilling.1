# Decisions: 장비 레이어 전체 정렬

## 최신 결정: 공통 장비 기준으로 캐릭터 재설계

사용자 지시: 기본 갑옷의 자세와 비율을 기준으로 캐릭터 베이스를 다시 만들고, 동일한 좌표의 투구·갑옷·장갑·장화·창·말 장비 레이어를 교체한다. 각 동작과 마을 포즈마다 캐릭터와 장비가 같은 기준을 공유해야 한다. 희귀도는 해당 부위 레이어만 교체한다. 이전의 임의의 단일 런타임 transform 방식은 폐기한다. 기존 artwork는 부위 원본으로 사용하되 포즈별 기준 좌표로 프레임에 합성한다. 시각적으로 확인되기 전까지 작업 완료로 기록하지 않는다.

- Date: 2026-10-27
- Status: Confirmed
- Scope: 무장 장비가 중복된 기수 베이스를 정리하고, 여섯 장비 슬롯의 걷기·전투·마을 합성 위치를 바로잡는다.

## D01. 베이스 기수
- **Chosen**: 걷기와 전투 베이스에서는 투구·갑옷·장갑·장화·창을 제거하고, 장비를 덧씌울 수 있는 기본 천 옷차림의 기수로 교체한다. 포즈 순서와 투명 프레임 규격을 유지하고 전투 포즈는 공통 접지선에 정렬한다.
- **Chosen**: 기존 장비 그림의 선화·음영·색상과 희귀도별 색상·장식은 유지한다. 마을 입상 베이스는 기존 별도 이미지를 계속 사용한다.

## D02. 슬롯 합성 정렬
- **Chosen**: 투구·갑옷·장갑·장화·창·말을 각각 슬롯별 크기와 기준 위치로 배치한다. 같은 슬롯 설정을 4개 걷기 프레임과 6개 전투 프레임 전체에 적용하며 프레임마다 런타임 오프셋을 두지 않는다.
- **Chosen**: 마을 입상 기사와 말 미리보기에는 별도의 슬롯별 배치 기준을 적용한다. 프레임 10의 장비 외형과 희귀도 색은 유지한다.
- **Chosen**: 일반·랭킹 전투, PvP 양쪽 캐릭터, 마을 미리보기에 동일한 합성 규칙을 적용한다. 장비 상태·전투·저장·PvP 티켓 데이터는 바꾸지 않는다.

## D03. 기존 프레임 계약
- **Chosen**: 12칸 장비 atlas 계약을 유지한다. 0–3은 걷기, 4–9는 전투, 10은 마을 입상, 11은 투명 패딩이다. 6부위×5희귀도의 기존 장비 그림과 희귀도 팔레트를 유지한다.
- **Chosen**: 전투 베이스는 6프레임 포즈 순서, 256px 셀, 투명 배경을 유지하고 각 action frame의 접지를 atlas 픽셀 단계에서 `ground=244`로 맞춘다. 걷기 기수는 기존 1205×1305 캔버스 안에서 유효 실루엣 높이로 스케일한다.

## 확인된 근거
- `public/assets/walk/knight-rider.png`에는 전신 판금, 투구, 장갑, 장화, 창이 포함되어 있다.
- `public/assets/walk/knight-actions.png`의 6개 프레임에도 같은 장비가 이미 그려져 있다.
- `EquipmentAppearance`는 여섯 슬롯 이미지를 같은 원점·크기로 한 좌표에 그린다. 개별 장비 atlas 셀 내부 그림 크기는 슬롯별로 다르다.
- 결과적으로 베이스와 overlay의 장비 중복에 각 슬롯 크기 차이가 더해져 첨부 화면처럼 큰 장비 뭉치로 보인다.

## 2026-10-27 화면 확인 후 수정

사용자가 전투와 마을에서 장비가 신체에서 분리된 화면을 제시했다. 기존 시트에는 잘린 조각이 있어 슬롯별 고정 좌표만으로는 프레임 정렬이 불가능하다. 원본과 희귀도 색을 보존하면서 온전한 장비 조각을 각 동작에 맞춰 별도 atlas로 재구성하고 합성 그룹 전체를 반전한다. 실제 화면 검증은 별도로 필요하다.

## 최신 구현 결정

장비 착용 디자인은 여섯 장비 슬롯의 레이어 조합으로 표현한다. 걷기/전투의 비무장 기수는 공통 underlay이고, Common 완성 외형도 Common 부위 레이어를 얹은 결과다. 부위/희귀도를 바꾸면 그 atlas만 바뀐다. 같은 레이어 프레임 안에서 부위가 해당 포즈의 신체 위치에 맞도록 위치를 미리 합성하고 캐릭터와 같은 기준으로 좌우 반전한다. 이미지 생성으로 전체 캔버스가 재구성된 시안은 위치를 보존하지 않아 게임 asset으로 사용하지 않는다.
