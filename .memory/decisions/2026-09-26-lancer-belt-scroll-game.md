# Decisions: 마창기사 벨트스크롤 웹게임

- Date: 2026-09-26
- Status: Confirmed
- Feature slug: `lancer-belt-scroll-game`

## D01. 게임 형태와 실행 환경
- **Chosen**: 브라우저에서 실행하는 2D 횡스크롤 벨트스크롤 액션 RPG.
- **Chosen**: Phaser 게임 프레임워크, JavaScript, Vite를 사용한다.
- **Chosen**: 전투 화면은 단순 도형으로 구현한다. 장비를 바꾸면 투구·갑옷·장갑·신발·창·말 외형도 도형으로 바뀐다.
- **Chosen**: UI는 한국어만 지원하고, 오디오는 포함하지 않는다.
- **Rationale**: 좌우 이동, 카메라 추적, 충돌, 키보드·터치 입력이 핵심인 2D 게임에 프레임워크를 사용한다.

## D02. 시점, 화면, 조작
- **Chosen**: 측면에서 보이는 마창기사가 좌우로만 이동한다. 공격 버튼은 없고 적과 몸통 충돌해 전투한다.
- **Chosen**: 긴 전장을 좌우로 진행하며 카메라가 플레이어를 따라간다.
- **Chosen**: 데스크톱에서는 A/D 키, 모바일에서는 가로 화면의 왼쪽·오른쪽 절반을 누르고 있는 동안 이동한다. 손을 떼면 멈춘다.
- **Chosen**: 모바일 세로 모드는 지원하지 않는다.

## D03. 충돌 전투와 피해 계산
- **Chosen**: 접촉이 시작될 때 한 번 피해를 교환한다. 밀려나 다시 접촉하면 새 충돌로 계산한다.
- **Chosen**: 플레이어만 밀려난다. 충돌 후 무적 시간은 없다.
- **Chosen**: 플레이어 공격력 대 적 방어력, 적 공격력 대 플레이어 방어력을 독립적으로 비교한다.
- **Chosen**: 공격력이 방어력보다 높으면 차이만큼 방어 측 HP가 줄어든다. 공격력이 방어력보다 낮으면 차이만큼 공격 측 HP가 줄어든다. 같으면 피해가 없다.
- **Chosen**: 플레이어가 주는 치명타는 공격력을 먼저 배율 처리한 다음 적 방어력과 비교한다.
- **Chosen**: 적 HP 감소를 먼저 적용하고 적이 쓰러지면 이후 플레이어 HP 감소는 취소한다.
- **Chosen**: 기본 치명타 확률 5%, 치명타 공격력 2배, 치명타 확률 상한 100%. 치명타는 플레이어 공격에만 적용한다.
- **Rationale**: 양방향 공격·방어 계산을 분리하고, 한 접촉에서 적이 쓰러지면 반격을 막는 규칙이다.

## D04. 플레이어 기본 능력치와 성장
- **Chosen**: 장비 보너스 적용 전 최대 HP 100, 공격력 10, 방어력 5.
- **Chosen**: 플레이어 레벨은 상한이 없다. 레벨업 때 전투를 멈추고 공격력(+2), 방어력(+5), 최대 HP(+10) 중 하나를 고른다.
- **Chosen**: 적 처치 10 XP, 스테이지 완료 100 XP, 보스 처치 추가 200 XP.
- **Chosen**: 다음 레벨 요구 XP의 시작값은 100이며, 장비 강화 비용과 같은 증가 규칙을 적용한다(규칙은 D10 참조).
- **Chosen**: 재플레이 시 경험치는 최초 사냥·스테이지 보상의 30%만 받는다.

## D05. 장비 부위와 효과
- **Chosen**: 장비 부위는 투구, 갑옷, 장갑, 신발, 창, 말의 6종이다.
- **Chosen**: 투구와 갑옷은 다른 부위보다 방어력이 높은 편이다. 장갑과 신발에는 치명타 확률 및 치명타 피해 옵션이 붙는다. 이동 속도를 높일 수 있는 장비는 말뿐이다.
- **Chosen**: 유니크와 레전더리 장비에는 전투에 직접 영향을 주는 자동 발동 고유 효과가 붙는다. 예시는 추가 피해, 흡혈, 피해 감소, 밀쳐내기 강화 등이다.
- **Chosen**: 고유 효과 종류는 아이템마다 고정한다. 무작위로 생성된 효과 조합은 그 장비에 저장되며, 강화로 수치가 바뀌어도 효과 종류는 바뀌지 않는다.
- **Chosen**: 장비 등급은 커먼(회색), 언커먼(흰색), 레어(파란색), 유니크(보라색), 레전더리(노란색)이다.
- **Chosen**: 등급별 기본 능력치 배율은 커먼 1, 언커먼 1.5, 레어 2, 유니크 3, 레전더리 5이다.
- **Chosen**: 같은 부위·등급이어도 장비 획득 시 기본 능력치는 기준값의 ±25% 범위에서 무작위로 정한다.
- **Chosen**: 유니크 효과는 1개일 확률 80%, 2개일 확률 20%. 레전더리 효과는 1개 50%, 2개 40%, 3개 10%다.
- **Chosen**: 효과별 등급 수치는 기본 능력치 배율을 그대로 쓰지 않고 효과마다 별도로 조정한다. 같은 효과가 여러 장비에 있으면 중첩하며, 치명타 확률은 100%를 넘지 않는다.
- **Rationale**: 기본 능력치와 개별 효과의 밸런스를 분리해 조정한다.

## D06. 장비 강화와 분해
- **Chosen**: 장비 강화 최대 레벨은 30이다. 강화는 실패하지 않는다.
- **Chosen**: 강화 시 능력치만, 효과만, 또는 둘 다 오를 수 있고 결과는 같은 확률로 무작위 결정한다. 효과가 없는 장비는 능력치만 오른다.
- **Chosen**: 강화할 능력치와 효과도 각각 무작위로 선택한다. 둘 다 오르면 능력치 하나와 효과 하나를 각각 선택한다.
- **Chosen**: 선택된 값은 현재 수치의 무작위 1~5%만큼 증가하며 감소하지 않는다.
- **Chosen**: 첫 강화(1→2)의 비용은 공용 재료 10개다. 일반 레벨 구간에서는 다음 레벨 비용이 20% 증가한다. 다음 레벨이 5의 배수면 1.5배, 10의 배수면 2배를 적용하며, 경계 레벨에서는 20% 증가 대신 해당 배율만 적용한다. 비용은 올림한다.
- **Chosen**: 공용 재료는 장비 분해로 얻는다. 기본 수량은 커먼 1, 언커먼 2, 레어 4, 유니크 8, 레전더리 16개이며, 분해마다 5% 대성공 확률이 있다. 대성공 시 수량이 2배다.
- **Chosen**: 경험치 요구량도 첫 레벨 요구량 100에서 시작해 강화 비용과 같은 레벨별 20%, 5레벨 1.5배, 10레벨 2배 규칙을 따른다.
- **Rationale**: 강화와 경험치 성장 모두 점차 가파르게 만들고, 5·10레벨 경계에서 추가 상승시킨다.

## D07. 시작 상태, 인벤토리, 장비 관리
- **Chosen**: 새 게임은 마을에서 시작한다. 기사는 여섯 부위 모두 커먼 장비를 착용한다.
- **Chosen**: 장비 인벤토리는 장착 중인 장비를 제외하고 최대 20개다. 장착 장비는 인벤토리 목록 대신 장비창에 표시한다.
- **Chosen**: 장비는 플레이어가 닿으면 자동 획득한다. 인벤토리가 가득 차면 바닥에 남는다.
- **Chosen**: 마을에서 장비를 확인·교체·분해·강화하고 스테이지를 선택한다.
- **Chosen**: 장비 드롭의 부위는 여섯 부위가 같은 확률로 나온다.

## D08. 드롭과 등급 확률
- **Chosen**: 일반 적은 20% 확률로 장비를 떨어뜨리고, 보스는 장비 1개를 반드시 준다. 보스 등급도 해당 스테이지의 일반 등급 확률표를 따른다.
- **Chosen**: 1스테이지의 등급 확률은 커먼 60%, 언커먼 25%, 레어 10%, 유니크 4%, 레전더리 1%다.
- **Chosen**: 10스테이지 확률은 커먼 30%, 언커먼 25%, 레어 20%, 유니크 15%, 레전더리 10%다. 사이 스테이지에서는 두 분포 사이를 단계적으로 보간한다.
- **Chosen**: 재플레이에서도 장비 드롭 확률은 동일하게 적용한다.
- **Implementation note**: 각 장비 부위의 기준 능력치와 고유 효과 목록은 아직 코드에 없으므로 계획 단계에서 첫 버전용 값을 정의한다. 무작위 값은 아이템 획득 시 확정하고 아이템에 저장한다.

## D09. 스테이지, 적, 보스
- **Chosen**: 처음에는 일반 적 한 종류와 별도 보스를 구현한다. 일반 적은 제자리를 지키다가 플레이어가 가까이 오면 공격한다.
- **Chosen**: 스테이지마다 일반 적 10마리를 전장에 흩어 배치한다. 모두 처치하면 스테이지가 끝난다.
- **Chosen**: 매 5번째와 10번째 스테이지에서 일반 적을 모두 처치한 뒤 보스가 등장한다. 보스 처치 후 완료된다.
- **Chosen**: 같은 스테이지의 일반 적보다 보스는 HP 5배, 공격력 2배, 방어력 2배다.
- **Chosen**: 스테이지가 하나 오를 때마다 적의 공격력·방어력·HP가 10% 증가한다. 회차별 기준 배율은 1회차 1.0배, 2회차 1.5배, 3회차 2.0배처럼 매 회차 기준값의 0.5배씩 더한다.
- **Chosen**: 한 회차는 10스테이지다. 1-1~1-10 이후 2-1~2-10, 3-1~3-10 순으로 해금된다. 5·10 보스 간격은 각 회차에서 반복된다.
- **Chosen**: 스테이지를 마치면 마을로 갈지 다음 해금 스테이지로 바로 갈지 선택한다. 마을에서는 이전에 완료한 스테이지를 선택해 추가 파밍할 수 있다.
- **Chosen**: 스테이지 완료 후 HP는 최대 HP의 절반까지 회복하되, 현재 HP가 그보다 높으면 유지한다.

## D10. 사망, 재도전, 저장
- **Chosen**: HP가 0이면 게임 오버 후 현재 스테이지를 처음부터 다시 시작한다. 재시작 시 HP는 최대치로 회복하고 레벨·장비는 유지한다.
- **Chosen**: 사망한 스테이지에서 얻은 경험치는 유지한다. 해당 시도 중 획득한 장비를 포함한 다른 보상은 되돌린다.
- **Chosen**: 진행과 장비를 브라우저에 자동 저장해 새로고침과 재방문 뒤에도 이어간다.

## D11. 게임 완료와 마을 흐름
- **Chosen**: 10번째 스테이지 보스를 처치하면 마을로 이동하며 레벨과 장비를 유지한다.
- **Chosen**: 스테이지 10 완료 후 다음 회차가 해금된다. 마을에서 다음 회차 또는 이전에 완료한 스테이지를 고를 수 있다.
- **Chosen**: 새 게임 시작과 회차 전환에서도 보유 레벨과 장비를 보존한다.

## D12. 기존 저장소 확인과 범위
- **Confirmed by repository inspection**: 현재 저장소에는 `README.md`, `AGENTS.md`, 메모리 스타터 파일만 있고 게임 앱이나 `package.json`/프런트엔드 설정이 없다. 따라서 Phaser/Vite 프로젝트는 새로 구성해야 한다.
- **Confirmed by repository inspection**: 현재 경로는 Git 저장소가 아니어서 `git status`가 실패했다. 구현 단계의 커밋 절차를 진행하려면 Git 저장소 초기화가 필요할 수 있다.
- **Out of scope for this interview**: 코드 작성, 게임 밸런스 구현, 에셋 제작, 테스트 및 Git 초기화는 하지 않았다.
