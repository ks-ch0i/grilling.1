# Decisions: 스테이지 클리어 자동 습득

- Date: 2026-10-28
- Status: Confirmed

## D01. 습득 대상
- **Chosen**: 사용자가 2번을 선택: 클리어 시 바닥에 남은 모든 드롭을 자동으로 습득한다.
- **Rationale**: 마지막 적의 드롭과 놓친 드롭을 종료 화면 전에 회수한다.

## D02. 보관함과 실패
- **Chosen**: 기존 보관함 용량과 순서를 유지하고 사망 시 자동 습득하지 않는다.
- **Rationale**: 사용자가 선택하기 전에 용량 제한 유지를 명시했다.

## D03. 랭킹 재현 호환
- **Chosen**: 새 티켓은 v5 자동 습득 규칙; 기존 v4 재현은 종전 규칙을 유지한다.
- **Rationale**: 발급된 티켓의 검증 결과를 도중에 바꾸지 않는다. 배포하지 않는다.
