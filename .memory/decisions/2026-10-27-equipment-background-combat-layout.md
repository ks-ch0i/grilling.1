# Decisions: 장비 외형·배경 아트·전투 월드 축소

- Date: 2026-10-27
- Status: Confirmed
- Scope: 장비 외형 표시, 마을 미리보기, 마을·전투·PvP 배경 아트, 일반 적과 보스 배치 및 전투 월드 길이를 정한다. 이 문서 작성에서는 게임 코드와 기존 메모리 포인터를 변경하거나 테스트·커밋하지 않는다.

## D01. 장비 외형 규칙과 적용 화면
- **Chosen**: 장비 외형은 슬롯 실루엣과 희귀도로 결정한다. 같은 슬롯·희귀도는 같은 외형을 쓰고, 레벨과 능력치 수치는 외형에 반영하지 않는다.
- **Chosen**: 투구·갑옷·장갑·장화·창·말의 6부위별 투명 레이어를 만든다. 기존 장비 색을 유지하고 기존 희귀도 색상으로 작은 테두리·장식과 은은한 빛 효과를 더한다.
- **Chosen**: 부위별·희귀도별 외형을 공유하며, 총 6부위 × 5희귀도 조합을 만든다.
- **Chosen**: 마을 장비 화면과 일반·랭킹 전투, PvP의 양쪽 캐릭터에 장착 외형을 반영한다. 마을에서는 장착·해제 즉시 미리보기를 갱신한다.

## D02. 장비 레이어 프레임 정렬
- **Chosen**: 장비 레이어는 기사 스프라이트 시트와 같은 프레임 순서를 따른다. 대기·이동·공격·피격·쓰러짐 동작과 좌우 방향 모두에서 해당 부위에 붙어 움직인다.
- **Chosen**: 슬롯·희귀도별 장비 외형 파일 하나에 걷기 4컷과 공격·피격·쓰러짐 6컷을 함께 넣는다. 마을용 기본 입상 기사는 별도 이미지 파일로 둔다.
- **Chosen**: 기존 기마 전투 외형 위에 투명 레이어를 조합한다. PvP도 양쪽 모두 기마 상태를 유지하며 장비 외형을 표시한다.
- **Chosen**: 마을에서도 착용 장비를 입상 기사에 맞춰 표시하기 위해 같은 장비 파일에 서 있는 포즈용 레이어 1컷을 추가한다. 기본 입상 기사 파일은 별도이며, 남는 atlas 칸은 투명 처리한다.

## D03. 마을 장비 미리보기
- **Chosen**: 마을 상단 상태 영역에 약 144×80px 크기로 말을 왼쪽, 전신 기사를 오른쪽에 나란히 둔다. 각각 약 64px 크기로 표시한다.
- **Chosen**: 기존 장비 상세 패널은 유지한다. 미리보기와 정보가 함께 보이도록 상단 상태 영역을 재배치한다.
- **Chosen**: 미리보기용으로 장비 레이어를 적용할 별도 전신 입상 기사 이미지를 만든다.
- **Chosen**: 이 좌우 분리 배치는 마을 미리보기에서만 사용한다. 일반·랭킹 전투와 PvP는 기마 상태를 유지한다.

## D04. 배경 화면과 테마
- **Chosen**: 마을, 일반·랭킹 전투, PvP에 각 장면에 맞는 배경 아트를 적용한다.
- **Chosen**: 마을은 변경 마을 광장, PvP는 석조 결투장으로 구성한다.
- **Chosen**: 전투 배경 테마 5종은 숲길 → 폐허 마을 → 바위 협곡 → 설산 요새 → 화산 성채 순서다. 5챕터 주기로 순환하며, 각 챕터의 일반·랭킹 10개 스테이지는 같은 테마를 쓴다.
- **Chosen**: 배경 그림체는 비교 시안 2번인 부드러운 페인터리로 통일한다. 장비 그림체는 기존 기사 스프라이트 스타일을 유지한다.
- **Chosen**: 전투 배경은 원경·중경·전경을 나누고 카메라 움직임에 따라 약하게 시차 이동한다. 원경은 월드 길이 파노라마, 중경·전경은 자연스럽게 반복되는 타일로 만든다.
- **Chosen**: 마을과 PvP는 깊이감 있는 정지 배경을 쓴다.
- **Chosen**: 전투 배경의 하늘·지형은 아트로 바꾸되, 캐릭터가 잘 보이도록 낮은 디테일의 바닥 띠와 바닥선을 유지한다. 충돌 기준 `FLOOR_Y=560`은 유지한다.

## D05. 전투 월드와 적 배치
- **Chosen**: 전투 월드 X축 길이를 기존 11,200px에서 4,800px로 줄인다.
- **Chosen**: 일반 적 수는 기존 범위인 4~10마리를 유지한다. 같은 적 종류의 반복과 같은 x 좌표 중첩 소환을 허용한다.
- **Chosen**: 적은 x=700~3,100 구간의 세 군집에 고르게 나눈다. 군집마다 고정 x를 사용하므로 군집 내 적은 같은 위치에 겹쳐 소환된다.
- **Chosen**: 모든 일반 적 처치 후 가장 뒤쪽 군집에서 500px 뒤에 보스를 고정 소환한다.
- **계획 단계 계산값**: 세 고정 x는 선택된 700~3,100 구간을 균등 분할한 700, 1,900, 3,100px로 둔다. 가장 뒤쪽 군집 기준 500px 간격을 적용한 보스 x는 3,600px다. 이 값들은 선택된 범위·군집 수·보스 간격에서 도출한 구현 기준이다.
- **계획 단계 계산값**: 적 수가 세 군집에 나누어떨어지지 않으면 군집별 수 차이를 최대 1마리로 두고 앞쪽 군집부터 나머지를 배정한다.
- **Chosen**: 시뮬레이터 v4 전환 때 기존 v3 랭킹 티켓은 즉시 만료한다. 새 v4 티켓부터 랭킹 전투에 적용하며 v3 재생 호환은 제공하지 않는다.

## 자동 확인된 코드 제약
- 화면 기준은 1280×720px다. `BattleScene`은 카메라가 플레이어를 따라가며 현재 월드 경계를 11,200px로 사용한다.
- 일반 적 수는 `packages/game-rules/src/balance.js`의 4~10 범위다. 현재 일반 전투와 랭킹 시뮬레이션 모두 `700 + index × 950` 위치를 사용하고, 보스는 x=10,500에 생성한다. 두 경로는 동일한 군집 배치·보스 위치 규칙으로 갱신해야 한다.
- 전투 바닥 기준은 `BattleScene.js`와 `PvpScene.js`의 `FLOOR_Y=560`이다.
- 현재 전투 배경은 장면에서 색상 사각형과 반복 장식으로 만들며 배경 이미지 로딩은 없다. PvP 배경과 캐릭터도 현재 사각형으로 표시한다.
- `WholeBodyWalk`는 256×256 프레임의 말 스프라이트에 고정된 기수 이미지를 얹는다. 현재 `knight-rider.png`는 앉은 기수 포즈이며, 마을용 입상 기사는 별도 아트가 필요하다.
- 마을의 장비 상세 패널은 화면 오른쪽 영역에 있다. 상단 미리보기는 해당 패널과 현재 상태 정보가 함께 보이도록 배치해야 한다.
