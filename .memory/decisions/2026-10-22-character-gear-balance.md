# 결정: 캐릭터·장비 밸런스 및 강화 실패·파괴

- Date: 2026-10-22
- Status: Confirmed
- Scope: 캐릭터 능력치와 초기화, 장비 능력치와 강화, 강화 실패·파괴, 적 성장 및 골드 경제
- Supersedes: `.memory/decisions/2026-09-28-game-balance.md` 중 이번 결정과 충돌하는 내용. 기존 생명력 흡수 기본 효과와 대성공 안내 문구 결정은 유지한다.

## D01. 레벨업 능력치와 기존 캐릭터 이행

- **Chosen**: 레벨을 얻을 때마다 자유 능력치 포인트 2점을 준다. 포인트 1점은 공격력 +5, 방어력 +10, 최대 HP +30을 올린다. 두 포인트를 같은 능력치에 모두 배정할 수 있다.
- **Chosen**: 전투 중 얻은 포인트는 보유할 수 있으며 다음 도전을 시작하기 전까지 쓰지 않아도 된다.
- **Chosen**: 기존 저장 데이터는 레벨과 XP를 유지하고 새 기본 능력치로 초기화한다. 획득한 레벨에 해당하는 자유 포인트를 지급한다.

## D02. 능력치 초기화

- **Chosen**: 마을에서 다음 도전 시작 전에만 초기화할 수 있다. 배정한 레벨업 포인트를 모두 돌려주며 레벨, XP, 장비는 유지한다.
- **Chosen**: 첫 초기화 비용은 1,000골드다. 이후 초기화 비용은 사용 횟수마다 1.5배씩 기하급수로 증가하며 상한은 없다.
- **Chosen**: 초기화 비용은 스테이지나 챕터 진행도에 따라 증가하지 않는다.

## D03. 강화 실패와 장비 파괴

확률은 강화 시도 직전 장비 레벨을 기준으로 한다. 구간은 서로 겹치지 않으며 경계 레벨은 앞 구간에 포함한다. 예를 들어 레벨 5는 1–5 구간, 레벨 10은 6–10 구간이다. 실패와 파괴는 서로 별도로 판정하며, 파괴 판정은 성공·실패와 무관하게 매 시도마다 한다.

| 시도 직전 장비 레벨 | 실패 확률 | 파괴 확률 |
| --- | ---: | ---: |
| 1–5 | 0% | 0% |
| 6–10 | 5% | 1% |
| 11–15 | 15% | 3% |
| 16–20 | 30% | 6% |
| 21–25 | 50% | 10% |
| 26–30 | 70% | 15% |

- **Chosen**: 실패하고 파괴되지 않으면 장비 레벨과 능력치는 그대로다. 실패한 시도도 강화 재료를 소모한다.
- **Chosen**: 성공한 시도도 파괴 판정에 걸리면 장비가 파괴된다.
- **Chosen**: 강화 전에 현재 실패 확률, 파괴 확률, 대성공 확률을 표시한다.
- **Chosen**: 대성공은 기본 강화 성공 뒤에 별도로 5% 확률로 판정한다. 성공으로 선택된 능력치 증가량을 두 배로 한다.
- **Carry forward**: 대성공 메시지만 표시하고 수치 증가량은 메시지에 넣지 않는다.

## D04. 장비 능력치 증가와 장비 기준값

- **Chosen**: 일반 능력치(공격력, 방어력, 최대 HP)의 강화 증가량은 강화 시도 직전 장비 레벨별로 현재 값에 대한 비율로 정한다. 구간 경계는 D03과 동일하게 앞 구간에 포함한다.

| 시도 직전 장비 레벨 | 일반 능력치 증가량 |
| --- | ---: |
| 1–5 | 1–5% |
| 6–10 | 2–6% |
| 11–15 | 3–7% |
| 16–20 | 4–8% |
| 21–25 | 5–9% |
| 26–30 | 6–10% |

- **Chosen**: 특수 능력치 및 효과는 현재의 고정 가산 증가 범위를 유지한다. 퍼센트는 퍼센트포인트로 더한다.

| 특수 능력치/효과 | 일반 강화 증가량 | 상한 |
| --- | ---: | --- |
| 치명타 확률 | +0.1–1%p | 100% |
| 치명타 배율 | +0.01–0.10 | 없음 |
| 이동 속도 보너스 | +1–5%p | 없음 |
| 추가 피해 | +1–5%p | 없음 |
| 피해 감소 | +0.1–1%p | 100% |
| 생명력 흡수 | +0.1–1%p | 기존 전투 처리 유지 |
| 반사 피해 | +1–3%p | 없음 |

- **Chosen**: 대성공이면 해당 시도에서 굴린 증가량을 두 배로 한다. 기존 강화 대상의 무작위 선택 동작과 재료 비용 구조를 유지한다.
- **Chosen**: 기존 희귀도 배율(일반 1, 고급 1.5, 희귀 2, 유니크 3, 전설 5)과 장비 무작위 굴림 범위(0.75–1.25)를 유지한다. 밸런스 목표 산정은 평균 굴림값 1.0을 기준으로 한다.
- **Chosen**: 기존 장비의 정체성, 희귀도, 강화 레벨을 보존하고 장착·보유 중인 모든 장비 능력치를 새 밸런스에 맞춰 결정적으로 재산정한다. 강화 이력이 저장되지 않아 과거 개별 강화 경로를 그대로 복원할 수는 없다.

## D05. 적 수와 전투 난도 목표

- **Chosen**: 스테이지마다 일반 적 4–10마리를 균등 무작위 배정한다. 랭킹 재생이 재현되도록 수는 런 시드에 묶는다.
- **Chosen**: 새 레벨 1 캐릭터와 평균 굴림의 일반 시작 장비는 일반 적을 접촉 전투 2–3회에 처치하는 기준으로 맞춘다. 첫 스테이지의 평균 적 7마리를 처치한 뒤 남는 HP 목표는 30–50%다.
- **Chosen**: 기존처럼 5번째 스테이지마다 보스를 둔다. 5번째 스테이지 보스는 적절한 레벨·장비에서 접촉 전투 6–9회를 목표로 한다. 후반 보스는 같은 구간 일반 적보다 약 2배의 접촉 전투를 요구한다.
- **Chosen**: 1챕터 10스테이지의 일반 적은 접촉 전투 4–5회, 2챕터 1스테이지는 5–6회, 2챕터 10스테이지는 7–8회를 목표로 한다. 3챕터부터는 각 챕터가 이전 챕터 10스테이지보다 어렵게 시작하고, 한 챕터 안에서 약 2회분의 전투가 추가되도록 한다.
- **Chosen**: 1챕터 10스테이지 종료 시 평균 일반 적 7마리와 보스 처치 후 남는 HP는 10% 미만을 목표로 한다.
- **Chosen**: 기존 스테이지 사이 회복 규칙을 유지한다. HP가 최대 HP의 50% 미만이면 50%까지 회복하고, 50% 이상이면 그대로 둔다.
- **Implementation derivation**: 구체적인 적 기본 능력치와 스테이지·챕터 성장률은 위 처치 횟수 및 잔여 HP 목표를 만족하도록 산정한다. 기존의 선형 스테이지 성장과 곱셈형 챕터 성장 구조는 유지한다.

## D06. 골드 경제

- **Chosen**: 골드를 새 재화로 추가한다. 일반 적 처치마다 소량을 확정 지급하고, 스테이지 클리어 보상도 지급한다. 골드 획득량은 스테이지와 챕터가 진행될수록 증가하며 적 능력치 성장률의 절반을 적용한다.
- **Chosen**: 평균 일반 스테이지 수입은 처치 보상 30%, 클리어 보상 70%로 구성한다. 적 수는 평균 7마리로 계산한다.
- **Chosen**: 사망해도 이미 받은 처치 골드는 유지한다. 스테이지 클리어 보상은 클리어했을 때만 지급한다.
- **Chosen**: 보스 처치 보상은 일반 적 한 마리 처치 보상의 5배다.
- **Chosen**: 첫 초기화 비용 1,000골드를 마련하는 데 평균 약 4회 스테이지 클리어가 걸리도록 초기 수입을 맞춘다.
- **Chosen**: 기존 저장 데이터의 초기 골드는 0이다.
- **Implementation derivation**: 평균 7마리 및 30/70 분배를 반영한 시작 구간 기준안은 일반 적 1마리당 11골드, 스테이지 클리어 175골드, 보스 55골드다. 평균 일반 스테이지 수입은 252골드이며, 1,000골드 초기화 비용은 약 3.97회 평균 클리어에 해당한다. 확정된 사용자 목표는 “평균 약 4회 클리어”이며, 이 정수 보상값은 그 목표에서 산출한 초기 구현 기준이다.

## D07. 온라인 랭킹 기록과 밸런스 버전

- **Chosen**: 기존 랭킹 기록과 새 랭킹 기록을 같은 목록에 유지한다. 기존 기록은 기존 밸런스 버전의 결과로 보존하며 새 밸런스로 다시 검증하지 않는다. 변경 이후 새 기록은 새 밸런스 버전으로 검증한다.
- **Implementation constraint**: 랭킹 서버는 기존 기록의 검증 버전과 새 기록의 검증 버전을 구별해야 한다. 이 결정은 기존 온라인 랭킹·PvP 아키텍처의 나머지 범위를 바꾸지 않는다.

## 계획 단계에서 수치화할 항목

- 적 기본 능력치, 적 성장률, 장비 슬롯별 기준 능력치와 업그레이드 반올림은 전투 목표를 만족하도록 계획·실행 단계에서 구체화한다.
- 골드 성장률의 절대 계수는 새 적 성장률을 확정한 뒤 그 절반으로 산정한다.
- 기존 저장 형식에 자유 포인트와 골드를 추가하는 스키마 전환은 계획에서 호환성과 이행 순서를 정한다.
- 실제 구현, 밸런스 시뮬레이션, 테스트, 커밋은 이 인터뷰 범위에 포함하지 않는다.

## 범위 밖

- Azure 배포는 계획하지 않는다.
- 이전 온라인 PvP와 오프라인 동작 결정은 별도 결정 문서의 범위에 남긴다.
